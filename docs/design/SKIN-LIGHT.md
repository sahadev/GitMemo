# 浅色皮肤（Light Skin）取值与规则

用途：结构基准取 `B-instrument-v1.html`，视觉语言取 G 稿（`G-instrument-light.html`）。本文是**浅色皮肤的唯一取值来源**，数值可直接抄进 CSS。
深色皮肤保留 B 的现值，只补其中两处不达标（§2.4，已落地）。
皮肤维度：颜色、边框宽度、圆角随皮肤变；密度两套共用（§4）。
所有对比度为 WCAG 2.x 相对亮度公式实算结果，不是目测。

## 3 浅色下必须变什么、不许变什么

### 3.1 强调色：不换色相，只压明度

浅色 `#1f3bff`（色相 230°）、深色 `#5aa9ff`（色相 210°）——同一族电光蓝的两个明度端，不引入第二种色相。

理由不是审美偏好：强调色承担「当前所在」，必须与品牌同源。换色相（例如浅色用紫、深色用绿）会让同一产品在两种皮肤下像两个东西，用户换肤后要重新建立「哪里是我」的认知。

### 3.1b 选中态：只换底色，不反白

选中行 = `--gm-selected`（强调色 12% 叠在面板上）+ 左侧 2px `--gm-accent` 竖条 + **文字色不变**。

不要在文档或组件里写成「墨底白字」：`--gm-selected` 是底色变量，把它设成近黑而文字仍是 `--gm-text`，结果就是黑底黑字、字直接看不见。真要反白，组件必须同时切到 `--gm-on-selected`，那是组件改造，不是皮肤改值——当前没做，`--gm-on-selected` 未接线。

### 3.2 线：装饰线保持「几乎看不见」，控件边界是纯黑

浅色最容易犯的错是把分隔线画重，一重就变表格。

- 装饰线 `rgba(11,11,12,.26)`（叠在白底上 ≈ `#c0c0c0`，1.82）：只做分区与行分隔，允许「几乎看不见」。
- 控件边界 `#0b0b0c`（19.67）：输入框、复选框、可聚焦轮廓用它，并且是 2px（§1.4）。

判定方法：遮住界面只看线，能否分辨「这是一块可点的输入区」——能就是控件边界，用纯黑 2px；不能就是装饰，用 26% 黑 1px。

### 3.3 分区：靠线，不靠底色差

浅色下画布与面板同为 `#ffffff`，明度比 1.00，靠底色差分区根本无从谈起。

结论：所有分区边界画 `--gm-line` 或 `--gm-line-strong`，不靠底色差、不靠投影、不用浅灰块（除了表头与代码块这类真正的「内嵌」，它们用 `#f5f5f2`）。

### 3.4 不许变的部分

- 字号阶梯、字距、行长
- 间距阶梯、行高
- 图标尺寸与图标风格
- 组件结构、DOM 层级、选中态写法（左侧 4px 强调条 + 底色）
- 动效时长与曲线
- 状态色语义（绿成功 / 琥珀警告 / 红危险）

### 3.5 边框粗细：可以随皮肤变，方向相反

结论：**浅色 2px 纯黑，深色 1px 低对比**。这是皮肤层里唯一允许的非颜色变量。

原因是两套皮肤的「线承担多少视觉重量」不同，不是审美口味：

- 浅色下 1px 黑线在白纸上会显得灰、显脏，2px 才足以把「面板」和「纸」分开；G 稿的识别特征正是这套粗框。
- 深色下 2px 高对比线会变成发光的栅栏——黑底上每一格都被框出来，密度感立刻变成监控墙。深色继续用 1px，且控件边界用 `#616d78` 而不是纯亮色。

同一结构、两种粗细，换来的是「同样的分产权重」而不是「同样的像素宽度」。

几何可以随皮肤变，但**盒子的外部尺寸不许变**：边框从 1px 变 2px 时，布局宽度与高度必须由 `box-sizing: border-box` 吸收，不允许整块变宽一像素导致换肤后列表错位。圆角同理，只改视觉轮廓，不改占位。

### 3.6 数字字重与字距：属于排版，两套共用

G 稿的 800 字重与 `-0.02em` 负字距是排版参数，不是皮肤值：两套皮肤都设 800 / `-0.02em`，皮肤块里不写 `font-weight` 与 `letter-spacing`。

否则换肤会改变数字的占位宽度，统计带会跳一格，用户会以为数据变了。

## 4 皮肤的合法维度

三个维度随皮肤变，一个不随：

| 维度 | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| 颜色 | G 语言全套 | B 现值 + §2.4 修正 | 唯一必须逐项给出取值的维度 |
| 边框宽度 | 2px | 1px | 见 §3.5 |
| 圆角 | 0 | 4px | 见 §1.4 |
| 密度 | 32/30/34px 阶梯 | 同一套 | **不随皮肤变**：位置与尺寸影响肌肉记忆，两套共用一套取值 |

判定一条变量是否属于皮肤层：换个值会不会改变「气质」而不改变「结构占位」。会改气质、不改占位的，属于皮肤（颜色、边框宽度、圆角）；会改变占位、信息量或点击位置的，属于结构（密度、字号阶梯、行高、间距语义、组件结构）。

两条硬约束：

1. **几何变化不得改变盒子外部尺寸**。边框加粗、圆角变化都由 `box-sizing: border-box` 吸收，换肤前后同一列表的行高、列宽、总高必须逐像素一致。
2. **皮肤块里不写排版属性**。`font-weight`、`letter-spacing`、`font-size`、`line-height` 不进皮肤块——G 的 800 字重与 `-0.02em` 负字距属于排版，两套皮肤共用（见 §3.6）。否则换肤会让数字占位宽度变化，统计带跳一格。

# 浅色皮肤（Light Skin）取值与规则

用途：结构基准取 `B-instrument-v1.html`，本文是**浅色皮肤的唯一取值来源**，数值可直接抄进 CSS。
深色皮肤保留 B 的现值；浅色是它的镜像，不是另起一套设计。
所有对比度为 WCAG 2.x 相对亮度公式实算结果，不是目测。

## 3 浅色下必须变什么、不许变什么

### 3.1 强调色：不换色相，只压明度

深色 `#5aa9ff` 的色相约 210°（偏青的蓝），浅色用 `#0b62c4`，色相同为 211°。**只降明度，不换色相**。

理由不是审美偏好：强调色在这套结构里承担「当前所在」，它必须和品牌同源。换色相（例如浅色换成紫或橙）会让同一产品在两种皮肤下看起来像两个东西，用户换肤后要重新建立「哪里是我」的认知。

配套两条：悬停用同色相的更深一档 `#0a55ab`；强调填充上的字用纯白（5.51），不用半透明白。

### 3.2 线：装饰线保持「几乎看不见」，控件边界必须抬到 3.0 以上

浅色最容易犯的错是把分隔线画重——一重就变表格，整屏像 Excel。

- 装饰线 `#dfe3ea`（1.20）：只做分区与行分隔，不承担信息，允许「几乎看不见」。
- 控件边界 `#7d8794`（3.40 / 3.64 / 3.16）：凡是「这条线用来判断控件边界」的地方（输入框、复选框、可聚焦轮廓），必须用这一档。

判定方法：遮住界面只看线，能不能分辨「这是一块可点的输入区」——能，就是控件边界，用线强；不能，就是装饰，用线弱。

### 3.3 面板之间：靠线，不靠底色差

浅色下画布 `#f6f7f9` 与面板 `#ffffff` 的明度比只有 1.05，靠底色差分区会看起来像「没画干净」的脏边。

结论：面板与画布之间**一律画 1px `--gm-line`**，不靠底色差、不靠投影。深色同理（B 现值画布/面板比 1.07，也是靠线）。

### 3.4 不许变的部分

以下属于结构，皮肤不许碰：

- 字号阶梯、字重、字距、行长
- 间距阶梯、行高（表格行 33px、列表行 32px 等）
- 圆角档位、边框粗细（1px 就是 1px，浅色不许加粗）
- 图标尺寸与线性图标风格
- 选中态写法（左 2px 强调条 + 底色）、状态色语义（绿成功 / 琥珀警告 / 红危险）
- 动效时长与曲线
- 组件结构与 DOM 层级

### 3.5 必须跟着变的部分

- 全部 14 组语义色（含浅底与遮罩）
- 强调填充上的反白文字颜色（深色 `#0b1015` → 浅色 `#ffffff`）
- 悬停与选中的实现方式：深色可用 `rgba(255,255,255,.04)` 叠亮，浅色必须用实色 `#f1f3f7`，否则叠出来发灰
- 对话框遮罩透明度：深色 0.55 → 浅色 0.32，浅色下 0.55 会把底下的白纸压成灰泥

## 4 圆角与密度能不能随皮肤变

**不能。** 一句话理由：圆角与密度是结构参数，皮肤只换颜色——让它们随皮肤浮动，等于一套皮肤就是另一个产品，换肤会改变用户已经形成的点击与扫读肌肉记忆。

落地口径：两套皮肤共用同一份 `--gm-r-1..4`、`--gm-density-*`、字号与行高（实现见 `desktop/src/index.css` 的「结构参数」块）；皮肤块里只允许出现颜色变量，出现任何非颜色变量即视为皮肤越界。

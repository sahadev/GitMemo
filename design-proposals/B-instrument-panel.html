方向 B（仪器面板）的出处与取舍

取自 awwwards 当期 Sites of the Day 清单（2026-10-23 抓取）。清单是从 RSS feed 拉的；列表页是前端渲染， HTML 里没有条目。下面四件作品的数值不是凭印象写的，是把它们的线上 CSS 拉下来统计得到的： 网格列数、gap、font-size 的出现频次。

借了什么 / 不借什么

1. Overworld Audio — awwwards 页 / 线上站
线上 CSS 里 grid-template-columns 同时存在 repeat(12,…) 与 repeat(24,1fr) 两套，沟槽变量 --grid-gutter: 1rem（16px）， 微标签字号 9px / 10px / 12px（0.5625 / 0.625 / 0.75rem），大节间距 48px（3rem）。 借：12 列 + 固定沟槽的骨架；10 / 12px 两档微标签；48px 的大节间距。
不借：全屏地图式导航、音频自动播放、9px 那档（中文在 9px 下笔画糊掉）。

2. Signal-A Studio — awwwards 页 / 线上站
Webflow 样式表里 12 列网格出现 27 次 1fr ×12、23 次 minmax(0,1fr) ×12；row-gap/column-gap 最常用 10 / 16 / 20px； 等宽字用于 11 / 12 / 13 / 14px 的标签与元信息。借：minmax(0,1fr) 的等宽列 （比裸 1fr 更抗长路径撑破）；24px 沟槽；11–13px 的等宽元信息。 不借：80px 级展示标题、Lenis 平滑滚动、成组的入场动效。

3. Lidar Drone Scanning — awwwards 页 / 线上站
线上 CSS 用 repeat(12, minmax(0,1fr))，主区是 1fr 420px（内容 + 定宽侧栏）；字体是 Switzer + Proto Mono，展示字到 240px。 借：数字一律等宽（本地用 ui-monospace / Menlo 代替 Proto Mono， 不引外部字体）；细线框 + 定宽侧栏的信息节奏。不借：WebGL 点云、全屏 3D、 240px 巨字（对读数没有增益，只会把一屏挤成一页）。

4. Heron AI — awwwards 页 / 线上 dashboard 页
间距以 0.4 / 0.8 / 1.2 / 1.6rem 为主（4 / 8 / 12 / 16px），12 列网格，正文 14px（1.4rem）。 借：4px 基频的间距节奏；12 列；14px 上下的正文。不借：卡片圆角、 柔和渐变、插画化空状态——它们把工程工具做成了 SaaS 落地页。

没有从 FORMAT、Cartier 这类偏展览版式的作品里借任何东西：方向 B 要的是仪表读数， 不是杂志跨页。

这一版实际用的数值

项取值来源 / 理由
网格12 列 minmax(0,1fr)，沟槽 24px，页边 32pxSignal-A、Lidar；24px 让 1440 下每列 92px，够放 4 个中文词
分栏主区 8 / 4，底部 4 等分读数条Lidar 的 1fr 420px 在 1440 下右栏只有 420，改成 8/4 = 904/440
间距阶梯4 / 8 / 12 / 16 / 24 / 32 / 48 / 64Heron 的 4px 基频，向上并到 8 档，避免出现 20、28 这类非阶梯值
字号阶梯10 / 11 / 12 / 13 / 15 / 20 / 30Overworld + Signal-A 的 9–14px 微标签收成 10/11/12/13；读数 30px 是唯一的大字
数字等宽 + tabular-numsLidar 的 Proto Mono 观感，用系统等宽实现，零外部资源
线1px，#262b25（分隔）/ #1c211c（行内）只有两档线色；不做线框 + 阴影叠加
圆角2px（仅按钮、标签、输入框）仪表面板保持切角，不做卡片圆角
颜色底 #0c0e0c、面板 #121512、字 #e9e7df；绿 #4fbf7f 仅表「已同步」，琥珀 #d9a441 仅表「待推送 / 今日」状态色只留两个，红色未使用；类型靠 CV/MN/SC/CL/PL 字母码区分，不靠颜色
整页高度1440 × 889，一屏放下（不含下方说明区）读数条不做折叠，避免「要点开才看得到状态」
刻度尺8px 小刻度、24px 长刻度，宽 10px，透明度降到底Overworld 的标尺语言；用来给左侧一条固定参照，不加重视觉

和方向 C（纸面）的分界

B 靠对齐与读数密度取胜，留白只出现在面板内部；C 靠纸面留白与单栏阅读取胜。 如果评审要「信息一眼扫完」，B 更合适；要「读起来像手册」，C 更合适。两者共用同一套 4px 间距基频与 12 列骨架，后续无论选哪个，规范可以只改字号与留白两项。
